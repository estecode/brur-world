# Issue #168 — optional production buildings

The normal game composes the existing production `BuildingStreamLayer` with a `HUS` toggle in the map-control row. The layer is explicitly OFF by default. Production uses derived `world_data/building_tiles` generated from the authoritative `buildings.jsonl` export; the full Sweden build derives those tiles after the heavy building pass. The local PR check rebuilds only the derived building tiles from existing local runtime data before the exact-PR visual check.

No harness code is a production dependency, and no alternate building truth is introduced.
